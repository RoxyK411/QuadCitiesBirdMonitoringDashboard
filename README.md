🐦 Quad Cities Bird Monitoring Network
A Mississippi River Flyway Community Science & Conservation Platform

Overview
The Quad Cities Bird Monitoring Network is a lightweight, open‑source dashboard designed to visualize bird observations across the Mississippi River Flyway. It supports community science, conservation planning, and public engagement by making local bird activity easy to explore.

Features
📊 Interactive dashboard built with HTML, CSS, and JavaScript

🗺️ Geo‑referenced bird observations from QC community science contributors

🔍 Species‑level filtering and quick‑view summaries

🌎 Mississippi River Flyway context for migration and habitat insights

🧩 Lightweight JSON dataset (qc_birds.json) for easy updates and expansion
